# Web Personal de Nelson Lozano

Portafolio profesional de **Nelson Lozano**, Ingeniero de Software y Front End Developer.

Next.js · React · TypeScript · Tailwind CSS · Motion

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Contenido

Los textos y datos editables están en `data/` y `lib/i18n/dictionaries/`.
Define `NEXT_PUBLIC_SITE_URL` (ver `.env.example`) antes de publicar.
